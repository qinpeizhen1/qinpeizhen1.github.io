为什么建立个人研究资料库

互联网信息很多，但“看过”并不等于“拥有”。真正有价值的是把零散资料转成可检索、可引用、可复盘的长期资产。

目标

我的目标不是做一个更大的收藏夹，而是建立一条稳定的信息处理链：

公开网页 / 飞书 / PDF
        ↓
采集与保真
        ↓
Markdown + PDF + Metadata
        ↓
分类、搜索、去重
        ↓
研究、复盘、形成观点

为什么 Markdown 是主格式

PDF适合保留原貌，DOCX适合人工编辑，而 Markdown 更适合长期检索、版本管理、批量处理和后续 AI 分析。

执行原则

  • 先保证采集稳定，再做复杂知识库。
  • 原始资料与公开观点分开存放。
  • 每份资料保留来源 URL 和采集时间。
  • 把“事实、推断、假设”分开记录。
  • 项目记录必须包含下一步动作，而不是只做总结。

下一步

第一阶段先完成飞书和普通网页的稳定采集，再逐步扩展到批量导入、搜索、去重和结构化研究。
