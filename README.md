# qinpeizhen1.github.io

个人研究、项目与博客站点。

## 上传方法

把本压缩包内的全部文件和文件夹上传到仓库根目录：

`qinpeizhen1/qinpeizhen1.github.io`

然后在 GitHub 仓库中打开：

Settings → Pages → Build and deployment → Deploy from a branch

选择：

- Branch: `main`
- Folder: `/ (root)`

保存后等待 GitHub Pages 部署完成。

网站地址：

https://qinpeizhen1.github.io/

## 目录

- `blog/` 博客
- `research/` 研究
- `projects/` 项目
- `resources/` 资源
- `assets/` 样式
- `robots.txt` 搜索引擎抓取规则
- `sitemap.xml` 站点地图
